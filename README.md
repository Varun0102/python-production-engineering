# Python and Production Engineering

From a Python prototype to a production service someone else can run.

AI can write a working Python script in 30 minutes. But can that script survive production? In this course we take one application, the Complaint Triage Service for a Zomato style food delivery platform, and carry it through four production gates until it runs on Amazon EKS.

    CONTRACT  -->  ASYNC  -->  SERVICE  -->  SHIP

AI writes code fast. Production engineering decides whether it ships.

## What is in this repository

| Folder | What you will find |
|---|---|
| 00-overview | What you will learn, prerequisites and setup checklist |
| 01-concepts | The context and concept behind every topic, in the same order as the class |
| 02-architecture | The full architecture of what we build and the deployment flow |
| 03-diagrams | The draw.io file used in class. Open it at https://app.diagrams.net |
| 04-code | The Complaint Triage Service, the AI stub service and the Kubernetes files |
| 05-labs | The hands on lab, step by step, from an empty AWS account to EKS |
| 06-interview-questions | Interview questions you can answer from the lab you built |

## How to use it

1. Read 00-overview before the class.
2. Keep 03-diagrams open during the class.
3. Follow 05-labs in order. Every part builds on the previous one.
